# Banco CN — Ciências da Natureza: ENEM e Vestibulares

Banco de 1.786 questões de Física, Química e Biologia:
- ENEM 2016–2025;
- FUVEST, UNICAMP, UNESP e IME 2016–2026;
- ITA 2019–2026.

Cada questão traz o gabarito oficial e a série sugerida do Ensino Médio. As habilidades seguem a BNCC (EM13CNT).

Na página dá para filtrar as questões, montar uma prova e salvá-la em PDF, em .html ou como planilha.

Os cadernos vêm do acervo aberto [provas-vestibulares](https://github.com/diogopelaes/provas-vestibulares) e, no caso do ENEM, do INEP e do projeto enem-api.

Projeto desenvolvido por Osvaldo Bezerra — Escola Estadual Frederico José Pedreira Neto, Palmas-TO.
